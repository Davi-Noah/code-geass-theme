## `geass-symbol.gif` and `geass-icon.png`

Animated adaptation of [Geass.svg](https://commons.wikimedia.org/wiki/File:Geass.svg),
drawn by [Koveras](https://commons.wikimedia.org/wiki/User:Koveras).

The original work and this adaptation are licensed under
[Creative Commons Attribution-ShareAlike 3.0 Unported](https://creativecommons.org/licenses/by-sa/3.0/).

Changes made for these adaptations: the symbol was recolored, resized and placed
on original dark backgrounds. The GIF adds subtle glow, scanline and slow
breathing-animation effects; the PNG is a static square icon with a restrained
glow for use in Visual Studio Code and the Marketplace.
