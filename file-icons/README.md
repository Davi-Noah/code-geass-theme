# Geass Requiem file icons

This hybrid theme uses Code Geass imagery for generic files, folders and selected
file categories, while retaining Seti's recognizable language/tool glyphs.

The directory vendors the Seti file icon theme distributed with Visual Studio
Code. Its upstream files are:

- `extensions/theme-seti/icons/vs-seti-icon-theme.json`
- `extensions/theme-seti/icons/seti.woff`

Source: <https://github.com/microsoft/vscode/tree/main/extensions/theme-seti>

The upstream package declares the MIT license. A copy is included in
`SETI-LICENSE.txt`.

See `geass-assets/README.md` for the themed assets and their individual terms.
